# FUTO Theme Studio 2.0

صانع ثيمات FUTO Keyboard حقيقي بصيغة ZIP/TOML، بواجهة Material 3 مخصصة للهاتف.

## أبرز المزايا

- معاينة حية عربية وإنجليزية.
- شريط تنقل علوي بين المعاينة، التخطيط، الأشكال، الألوان، الصور، الخطوط، التصدير والإعدادات.
- **1024 شكل زر مولد فعليًا**: 768 ثنائي الأبعاد + 256 ثلاثي الأبعاد.
- تعيين شكل مستقل لكل مجموعة، أو تجاوز المجموعة وتعيين شكل لزر واحد.
- تخصيص أزرار الكتابة، الشريط العلوي، الصف السفلي، الوظائف، المسافة، الإرسال والأزرار الخاصة.
- صور مستقلة للكيبورد، للمجموعة، أو لزر محدد.
- تكبير الأزرار والحروف العربية والإنجليزية بشكل مستقل في المعاينة.
- 40 خطًا عربيًا و40 خطًا إنجليزيًا مدمجة في المشروع، مع استيراد TTF/OTF ومعاينة قبل الاختيار.
- ألوان أحادية ومتدرجة وفاتحة وداكنة وحيوية، مع 30 لوحة جاهزة.
- استيراد ألوان HEX من رابط عبر الإنترنت.
- خلفية لون/تدرج/صورة.
- تصدير ZIP متوافق مع صيغة FUTO Keyboard Theme Configuration 1.0.
- تصحيح مشكلة الأرقام المحلية في TOML باستخدام `Locale.US`، لذلك لا يتم توليد `٠٫٣٦٧` بدل `0.367`.
- تحقق قبل التصدير.
- شبكة أشكال Lazy لتقليل استهلاك الذاكرة أثناء التصفح.

## بناء APK

GitHub Actions موجود في `.github/workflows/android-build.yml` ويستخدم Java 17 وGradle 8.10.2.

## ملاحظة الخطوط

صيغة FUTO التي حللناها من `animal-theme.zip` تحتوي على `[options.font]` واحد عام للثيم، وليست خانتين منفصلتين للعربية والإنجليزية. لذلك يفصل التطبيق الخطين في المعاينة والإعدادات، وعند التصدير تختار لغة التصدير لتحديد الخط الذي يوضع في `theme.txt`، بدل الادعاء بوجود خاصية غير مدعومة في صيغة FUTO.
